{AAAA} = année, {MM} = mois, {N} = compteur (qui continue d'un mois à l'autre, comme Axonaut). Prochain devis : —. Le numéro est attribué quand le devis quitte l'état « Brouillon ». Pour reprendre la suite d'Axonaut, mets ici le numéro qui suit le dernier devis Axonaut.
Axonaut crée automatiquement un nouveau produit dans ta base pour chaque ligne envoyée sans produit. Avec un produit générique (à créer une fois dans Axonaut, ex. « Divers »), les lignes libres l'utilisent avec leur propre désignation et leur propre prix, sans ajouter de produit.
